# MASTER SITE BRIDGE V1 — prototype hors production

Adaptateur pur du dossier unifié validé vers un client.json brouillon. Aucun accès Supabase, aucune publication, aucun média téléchargé. Les coordonnées et contenus proviennent du dossier; les URL médias, secteur, slug et QR sont des entrées explicites de l'atelier, jamais inventés. Le statut en_cours/livre est un garde-fou de prototype et non une autorisation serveur. Les traductions non validées sont exclues; le moteur conserve son repli FR.

Le lien de dossier Drive est conservé comme référence externe, non comme galerie automatique; app.js ne l'affiche pas encore. Les URL d'images/vidéos doivent être directement lisibles et vérifiées par un humain; HTTPS seul ne garantit ni accès ni type de contenu. Le pont réel atelier/Supabase et le contrôle des droits de publication restent hors de ce test. Les sites PREMIUM/EXTRA gardent leurs données complémentaires. Ne pas publier le brouillon sans contrôle humain.
